# Mid_IT11_Activity-5

**Journey to the Wealth **is an educational and interactive arcade-style game developed in Unity using C#. Set in a mysterious, nocturnal forest, players catch falling coins and answer math questions to claim their value—earning points for correct answers while risking the coin for incorrect ones. To ensure clear project documentation, the accompanying README details the game's title and educational purpose, lists the core development tools (Unity and C#), provides step-by-step instructions on opening and running the prototype, outlines the primary C# scripts, and explains the full workflow for saving, retrieving, and displaying player data.
